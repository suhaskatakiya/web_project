# AETHEL & CO. — Architecture, Spatial Design & Atelier

An ultra-classy, human-crafted web application created for a Web Technology (WebTech) academic project. Built with **React**, **Vite**, **Tailwind CSS**, and modern JavaScript.

---

## 🏛️ Project Concept & Highlights

**Aethel & Co.** is a contemporary architectural and interior design studio crafting timeless spaces, sculptural residences, and tactile environments worldwide (Zürich • Kyoto • New York). 

Rather than looking like an automated, cookie-cutter AI template, this website is intentionally styled like an elite, human-crafted design monograph with editorial typography, subtle micro-interactions, rich domain depth, and working interactive tools.

### Key Interactive Features:
1. **Live Studio Clock**:
   - Real-time studio clocks tracking active business hours across Zürich (CET), Tokyo (JST), and New York (EST).
2. **Interactive Daylight & Spatial Lighting Lab**:
   - Allows users to simulate how light falls on a living sanctuary across 4 circadian phases: *Alpine Dawn (06:30)*, *Solar Noon (12:00)*, *Golden Hour (18:15)*, and *Nocturne (23:00)*.
   - Interactive toggles for 2700K recessed cove sconces, soft atmospheric diffusion, live lux meter, and solar angle calculation.
3. **Curated Portfolio & Blueprint Inspector**:
   - Filter by typology: Private Residences, Cultural Pavilions, Hospitality & Baths, Spatial Interiors.
   - Click any card to launch the **Full Blueprint Modal** containing photo gallery slideshow, acoustic ratings, materials breakdown, and environmental certificates.
4. **Interactive Tactile Materiality Board**:
   - Explore raw architectural materials (Roman Navona Travertine, Shou Sugi Ban Yakisugi, Valser Gneiss Quarzite, Aged Brass, Clay Plaster) with origin mapping, acoustic damping scores, and lifecycle metrics.
5. **Interactive Project Feasibility & Scope Estimator**:
   - Sliders and selectors for spatial scale (200 m² – 2,000 m²), craftsmanship tiers, and ecological engineering (Geothermal, subterranean vaults, hydrotherapy pools).
   - Generates real-time projected construction timelines and investment benchmarks.
   - One-click **"Transfer Scope To Inquiry"** that auto-populates the consultation form!
6. **The Monograph Journal**:
   - Thoughtful, human-written philosophical essays on spatial design, shadow acoustics, and 100-year joinery.
   - Interactive reader modal.
7. **Private Commission Consultation Form**:
   - Interactive form with real-time validation, multi-select aesthetic affinities, and a confirmation dossier receipt generator (`#AET-2026-XXXX`).
8. **Dark / Light Mode**:
   - Seamless luxury dark theme with warm obsidian tones and champagne gold accents, with one-click toggle to crisp daylight mode.

## 🚀 Getting Started

### 1. Open Terminal in the project folder
```bash
cd ~/Desktop/"web project"
```

### 2. Start the Development Server
```bash
npm run dev
```

Then open the local URL in your browser (typically `http://localhost:5173`).

### 3. Build for Production
```bash
npm run build
```
